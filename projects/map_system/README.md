# Map System Project

Build a map system from scratch.

Topics:
- algorithms
- data structures
- optimisation
- system design
- graph theory

## 1. Problem Statement

Input
- Intersections
- Roads
- Distance/time/cost

Output
- Find the minimum-cost path from source node S to destination node T.

## 2. Progression

1. Graph Representation
2. BFS
3. Dijkstra
4. Priority Queue Optimisation
5. A*
6. Bidirectional Search
7. Preprocessing Algorithms
8. Contraction Hierarchies
9. Production Routing Systems
